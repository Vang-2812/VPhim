# VPhim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây VPhim dùng Next.js + Supabase, nguồn KKPhim, UI Hallmark màu B, tài khoản email/Google và quản trị người dùng.

**Architecture:** Next.js App Router render nội dung công khai phía server; adapter KKPhim chuẩn hóa phim và tập. Supabase Auth/PostgreSQL/Storage quản lý tài khoản và dữ liệu riêng với RLS; server kiểm tra người dùng active trước mọi thao tác ghi, kiểm tra admin trước thao tác quản trị. Player HLS lưu tiến độ, iframe fallback chỉ nhớ tập.

**Tech Stack:** Next.js 16, React tương thích peer dependency của Next, TypeScript strict, npm/package-lock, Supabase JS + SSR, hls.js, Zod, Vitest, Testing Library, pg cho kiểm tra SQL. CSS token Hallmark và icon Lucide; không thêm framework backend khác.

**Spec:** `docs/superpowers/specs/2026-11-07-vphim-design.md` — đã được người dùng duyệt ngày 2026-11-07.

## Shared Contracts

Task 1 định nghĩa `Result<T> = { ok: true; data: T } | { ok: false; code: ErrorCode; message: string }` trong `src/lib/result.ts`. `ErrorCode` gồm `CONFIG_MISSING`, `UNAUTHENTICATED`, `BLOCKED`, `FORBIDDEN`, `VALIDATION`, `NOT_FOUND`, `UPSTREAM_UNAVAILABLE`, `SAVE_FAILED`. Error message public bằng tiếng Việt; log không có credentials.

Task 2 định nghĩa `MovieSummary { id: string; slug: string; title: string; originalTitle: string | null; posterUrl: string | null; thumbUrl: string | null; year: number | null; quality: string | null; language: string | null }`, `Episode { key: string; label: string; slug: string; hlsUrl: string | null; embedUrl: string | null }`, `MovieServer { key: string; label: string; episodes: Episode[] }`, `MovieDetail extends MovieSummary { description: string; genres: string[]; countries: string[]; servers: MovieServer[] }`, `Page<T> { items: T[]; page: number; totalPages: number }`, `BrowseQuery { keyword?: string; type?: string; category?: string; country?: string; year?: number; sort?: 'updated' | 'year'; page: number }`, `CatalogOption { slug: string; name: string }` trong movie types.

Task 5 định nghĩa `MemberContext { userId: string; role: 'member' | 'admin'; membership: 'normal' | 'vip' }`. Context chỉ được tạo bởi `requireMember()` ở server, không nhận từ form/client. Task 4 tạo kiểu DB phản ánh migrations; Task 6 định nghĩa `Gender = 'male' | 'female' | 'unspecified'` trong profile validation.
