# SEO and GEO Optimization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement comprehensive Technical SEO, Open Graph & Twitter rich metadata, JSON-LD structured data (Movie, TVSeries, VideoObject, Breadcrumbs, FAQPage, WebSite), robots.txt, sitemap.xml, and Generative Engine Optimization (GEO with `llms.txt` and AI crawler indexing rules) for VPhim.

---

## File Structure Map

- **New files:**
  - `src/lib/seo/config.ts`: Base site origin resolver, metadata generators, description cleaner.
  - `src/lib/seo/schema-org.tsx`: Reusable JSON-LD generator components (`WebSiteSchema`, `MovieSchema`, `VideoObjectSchema`, `BreadcrumbSchema`, `FaqSchema`).
  - `src/app/robots.ts`: Next.js Metadata Route generating dynamic `robots.txt` granting access to Googlebot, Bingbot, and AI crawlers (`GPTBot`, `OAI-SearchBot`, `PerplexityBot`, `ClaudeBot`, `Google-Extended`).
  - `src/app/sitemap.ts`: Next.js Metadata Route dynamically aggregating core static routes and top movie catalog links for `sitemap.xml`.
  - `public/llms.txt`: Standard LLM context file for Generative Engine Optimization (ChatGPT, Perplexity, Claude, Gemini).
  - `tests/unit/seo-config.test.ts`: Unit tests for origin resolution, metadata sanitization, and JSON-LD structured data generation.
  - `tests/components/seo-schema.test.tsx`: Tests verifying JSON-LD injection and robots/sitemap responses.
- **Modified files:**
  - `src/app/layout.tsx`: Add `metadataBase`, global Open Graph, Twitter cards, and `WebSite` JSON-LD schema with SearchAction.
  - `src/app/(public)/phim/[slug]/page.tsx`: Full dynamic `generateMetadata` (title, description, og:image, canonical, keywords) + inject `MovieSchema`, `BreadcrumbSchema`, and `FaqSchema`.
  - `src/app/(public)/xem/[slug]/page.tsx`: Dynamic `generateMetadata` for watch page + inject `VideoObjectSchema` and `BreadcrumbSchema`.
  - `src/app/(public)/kham-pha/page.tsx`: Enhanced metadata for discovery page with canonical and Open Graph tags.
